# Azeem Mumtaz - Portfolio CV

Personal portfolio website showcasing my professional experience as a Principal Software Engineer and Solution Architect.

🔗 **Live Site:** [https://azeemigi.github.io](https://azeemigi.github.io)

## About

This is my professional portfolio and CV website, built with clean, modern HTML and CSS. It highlights my work in solution architecture, DevSecOps, and enterprise software engineering.

## Features

- 📱 Responsive design (mobile, tablet, desktop)
- 🖨️ Print-optimized styling for PDF export
- ⚡ Fast loading, no frameworks
- 🎨 Clean, professional design

## Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, CSS Variables)
- Google Fonts (Inter)
- Font Awesome Icons
